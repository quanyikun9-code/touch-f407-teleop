======================================================================
 Geomagic Touch -> STM32F407 双器械机台   每次启动操作说明
======================================================================

这份说明给第一次接触这套系统的人看。按顺序做，不要跳步。
所有命令都在“命令行”里输入，输完一行按一次回车。

项目文件夹：
  E:\master manipulator\主从协同逐步调试
如果项目放在别的位置，把下面所有路径换成你实际的位置。

----------------------------------------------------------------------
 双主手测试（下方其余章节保留原单主手流程）
----------------------------------------------------------------------

1. 在项目文件夹运行：python -B pc/bridge_dual.py --seconds 30
   干跑不打开串口，也不输出主手力反馈。先松开两只笔的按钮，再逐只测试：
   A（22119000410）只影响 M1/M2，B（22109000332）只影响 M4/M5。
   按住按钮 1 后沿 Z 推拉，按住按钮 2 后转腕。按下时记为零位。
   0 0 表示松手；A 0 表示速度为零但按钮仍按着；数字是带方向的脉冲频率。
   先逐只验证，再同时操作两只；松开一只，另一组的显示应继续变化。
   如果两只笔实际摆放相反，可用 --a 和 --b 交换默认序列号。

2. 在驱动器动力电断开的情况下烧录 firmware/Project/Output/Fire_F407ZG.hex。
   用 python -B pc/serial_console.py --port COM6 --cmd "DUAL?" 检查新版固件：
   应返回 OK DUAL V1。若串口号变化，用设备管理器确认并替换 COM6。
   继续保持动力电断开，运行 python -B pc/bridge_dual.py --port COM6 --live --seconds 15，
   用示波器逐轴确认 STEP/DIR，松手后对应轴应停发 STEP。

3. 确认驱动器控制电压档为 5V（动力电源仍为 24V）、设备空载、远离行程端点、
   急停可用后，再用同一条 --live 命令短点动。先逐只、逐轴验证方向与停止，
   再测试双手同时控制。桥接默认限速：直线 1600 Hz，旋转 400 Hz（与旧单主手桥接一致）。
   Ctrl+C 结束；通信中断时固件约 250 ms 停止遥控轴。不要把软件停机当作硬件急停。
   M3/M6 夹爪仍走触屏。触屏点动或回位接管对应组后，先松开该主手的两个按钮再重按。
   M4 未配置可用的回位基准；首测不要依赖软件行程保护。


----------------------------------------------------------------------
 一、开机前：把线接好（每次断电后重新上电都要检查）
----------------------------------------------------------------------

1. Touch 主手
   - USB 线：接到电脑，直接插机身 USB 口，不要经过 HUB/扩展坞。
   - 电源：原装电源适配器插 220V，DC 头插 Touch 背面。
   - 看灯：墨水井（笔架凹槽）里的蓝灯应“快闪两下”，说明自检通过。

2. 控制板（野火 F407 霸天虎）
   - 12V 电源接板子 DC 口。双器械固件显示上下两组：上方 M1–M3，下方 M4–M6。
   - 下方灰显且提示 DISABLED 时，M4–M6 还没有启用，先核对 second_instrument.h 接线配置。
   - USB 线接板子上的“USB转串口”口，另一头接电脑。

3. 驱动器与机台
   - 24V 电源打开（三台 SRX02-E）。
   - 确认机台周围没有人、没有杂物，手能够到急停。

4. 先不要碰笔，也不要碰机台。


----------------------------------------------------------------------
 二、打开命令行
----------------------------------------------------------------------

按键盘 Win + R，输入 cmd，回车，会出现一个黑色窗口。

在黑窗口里输入下面这行（复制粘贴也行），回车：

cd /d "E:\master manipulator\主从协同逐步调试"

说明：cd 是“进入文件夹”，/d 表示允许换盘符。
后面的路径必须用英文双引号包起来，因为路径里有空格和中文。


----------------------------------------------------------------------
 三、检查主手（每次 Touch 上电后都要做一次）
----------------------------------------------------------------------

1. 把笔杆插进墨盒（底座上的笔架凹槽），保持不动。

2. 在黑窗口输入：

python tools\3dtouch\code\touchpy\check_device.py

3. 看输出，必须满足：
   [1] 驱动        ok
   [2] USB 枚举    ok
   [3] HD API      ok
   calibration: ok
   servo loop: 接近 1000 Hz

4. 如果 calibration 不是 ok，输入下面这条做校准（笔要插在墨盒里）：

python tools\3dtouch\code\touchpy\calibrate.py

5. 如果第 2 步就失败（找不到设备），先检查 Touch 的电源和 USB 线，
   再重新执行 check_device.py。不要继续往下做。


----------------------------------------------------------------------
 四、试运行（干跑：只读主手，不会让机台动）
----------------------------------------------------------------------

在黑窗口输入：

python pc\bridge.py

正常会每隔 0.5 秒打印一行，例如：
   1.0s off      offset=  +0.000  hz=    +0

现在做两个测试：

测试 A：按住笔上的按钮 1，沿 Z 方向慢慢推、慢慢拉。
  屏幕上 offset 和 hz 应跟着变，模式显示 M1/Z。
  松开按钮 1，hz 回到 0。

测试 B：按住笔上的按钮 2，手腕绕竖直轴左右转（像拧门把手）。
  屏幕上 offset 和 hz 应跟着变，模式显示 M2/Yaw。
  松开按钮 2，hz 回到 0。

两个都正常后，按 Ctrl + C 退出（先按住 Ctrl，再按 C）。
窗口回到命令行提示符，才说明退干净了。


----------------------------------------------------------------------
 五、正式运行（机台会动，手放急停上）
----------------------------------------------------------------------

确认机台周围安全后，输入：

python pc\bridge.py --live

操作方式：
  按住按钮 1：推/拉笔 -> 控制直线轴 M1。
               偏离初始位置越远，转得越快；回中停。
  按住按钮 2：转手腕 -> 控制旋转轴 M2。
               转得越多越快；回中停。
  松开按钮：  对应电机立刻停。
  两个按钮一起按：全停。

夹爪 M3（不由主手控制）：
  先松开按钮 1 和按钮 2，直接按板子屏幕上的“夹具夹紧 / 夹具松开”。
  夹紧和松开必须交替按；按一次走一段固定行程。

结束运行：
  1. 先松开所有按钮。
  2. 在命令行按 Ctrl + C，等出现“停止”。
  3. 再关 24V 电源、12V 电源。


----------------------------------------------------------------------
 六、命令速查（每次启动就看这里）
----------------------------------------------------------------------

进入项目文件夹：
  cd /d "E:\master manipulator\主从协同逐步调试"

检查主手：
  python tools\3dtouch\code\touchpy\check_device.py

校准主手（笔插墨盒）：
  python tools\3dtouch\code\touchpy\calibrate.py

干跑（不动电机）：
  python pc\bridge.py

正式运行：
  python pc\bridge.py --live

看串口号（找不到 COM6 时用）：
  python -m serial.tools.list_ports -v

换串口运行（例如板子是 COM7）：
  python pc\bridge.py --live --port COM7


----------------------------------------------------------------------
 七、出问题怎么判断
----------------------------------------------------------------------

1. 提示“打开主手失败 / 设备可能已被另一个程序占用”
   - 关掉 Touch Diagnostic、厂家演示程序，或别的 python 窗口。
   - 设备同一时间只能被一个程序使用。

2. 提示“打开串口 COM6 失败”
   - 板子的 USB 线没插好，或者串口号不是 COM6。
   - 运行上面“看串口号”的命令，找到 “USB-SERIAL CH340 (COMx)”，
     再用 --port COMx 重新运行。

3. 板子屏幕黑一下、闪一下
   - 正常。板载 CH340 的 DTR/RTS 接在复位上，打开串口会让板子重启。
     脚本已经处理，等 1 秒就好。

4. 按了按钮但机台不动
   - 24V 电源没开、驱动器没使能、急停被按下，或者机台已经到限位。
   - 先松按钮、Ctrl+C，再检查硬件。

5. 机台方向反了
   - 直线反了：运行命令后面加 --no-invert1
   - 旋转反了：运行命令后面加 --invert2
   例：python pc\bridge.py --live --no-invert1

6. 任何异常、异响、撞机
   - 第一反应：拍急停、松按钮、Ctrl+C。
   - 不要先去看屏幕上的报错。


----------------------------------------------------------------------
 八、绝对不要做的事
----------------------------------------------------------------------

- 不要在机台运动时把手伸进运动范围。
- 不要按着笔上的按钮去点屏幕（会抢控制权）。
- 不要把驱动器的 ENA 当急停用，断使能可能让机构掉下来。
- 不要跳过“干跑”，直接 --live。
- 不要修改固件或接线后不重新校准就运行。
- 不要在开着 24V 的情况下插拔电机线。

======================================================================
 一句话流程：
 接线 -> cd 到项目 -> check_device -> calibrate（需要时）
 -> bridge.py 干跑 -> bridge.py --live -> Ctrl+C -> 断电
