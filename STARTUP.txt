======================================================================
 Geomagic Touch -> STM32F407 三轴机台   每次启动操作说明
======================================================================

这份说明给第一次接触这套系统的人看。按顺序做，不要跳步。
所有命令都在“命令行”里输入，输完一行按一次回车。

项目文件夹：
  E:\master manipulator\主从协同逐步调试（未完善）
如果项目放在别的位置，把下面所有路径换成你实际的位置。


----------------------------------------------------------------------
 一、开机前：把线接好（每次断电后重新上电都要检查）
----------------------------------------------------------------------

1. Touch 主手
   - USB 线：接到电脑，直接插机身 USB 口，不要经过 HUB/扩展坞。
   - 电源：原装电源适配器插 220V，DC 头插 Touch 背面。
   - 看灯：墨水井（笔架凹槽）里的蓝灯应“快闪两下”，说明自检通过。

2. 控制板（野火 F407 霸天虎）
   - 12V 电源接板子 DC 口，板子屏幕亮，显示 6 个蓝色按钮。
   - USB 线接板子上的“USB转串口”口，另一头接电脑。

3. 驱动器与机台
   - 24V 电源打开（三台 SRX02-E）。
   - 确认机台周围没有人、没有杂物，手能够到急停。

4. 先不要碰笔，也不要碰机台。


----------------------------------------------------------------------
 二、打开命令行
----------------------------------------------------------------------

按键盘 Win + R，输入 cmd，回车，会出现一个黑色窗口。

在黑窗口里输入下面这行（复制粘贴也行），回车：

cd /d "E:\master manipulator\主从协同逐步调试（未完善）"

说明：cd 是“进入文件夹”，/d 表示允许换盘符。
后面的路径必须用英文双引号包起来，因为路径里有空格和中文。


----------------------------------------------------------------------
 三、检查主手（每次 Touch 上电后都要做一次）
----------------------------------------------------------------------

1. 把笔杆插进墨盒（底座上的笔架凹槽），保持不动。

2. 在黑窗口输入：

python tools\3dtouch\code\touchpy\check_device.py

3. 看输出，必须满足：
   [1] 驱动        ok
   [2] USB 枚举    ok
   [3] HD API      ok
   calibration: ok
   servo loop: 接近 1000 Hz

4. 如果 calibration 不是 ok，输入下面这条做校准（笔要插在墨盒里）：

python tools\3dtouch\code\touchpy\calibrate.py

5. 如果第 2 步就失败（找不到设备），先检查 Touch 的电源和 USB 线，
   再重新执行 check_device.py。不要继续往下做。


----------------------------------------------------------------------
 四、试运行（干跑：只读主手，不会让机台动）
----------------------------------------------------------------------

在黑窗口输入：

python pc\bridge.py

正常会每隔 0.5 秒打印一行，例如：
   1.0s off      offset=  +0.000  hz=    +0

现在做两个测试：

测试 A：按住笔上的按钮 1，沿 Z 方向慢慢推、慢慢拉。
  屏幕上 offset 和 hz 应跟着变，模式显示 M1/Z。
  松开按钮 1，hz 回到 0。

测试 B：按住笔上的按钮 2，手腕绕竖直轴左右转（像拧门把手）。
  屏幕上 offset 和 hz 应跟着变，模式显示 M2/Yaw。
  松开按钮 2，hz 回到 0。

两个都正常后，按 Ctrl + C 退出（先按住 Ctrl，再按 C）。
窗口回到命令行提示符，才说明退干净了。


----------------------------------------------------------------------
 五、正式运行（机台会动，手放急停上）
----------------------------------------------------------------------

确认机台周围安全后，输入：

python pc\bridge.py --live

操作方式：
  按住按钮 1：推/拉笔 -> 控制直线轴 M1。
               偏离初始位置越远，转得越快；回中停。
  按住按钮 2：转手腕 -> 控制旋转轴 M2。
               转得越多越快；回中停。
  松开按钮：  对应电机立刻停。
  两个按钮一起按：全停。

夹爪 M3（不由主手控制）：
  先松开按钮 1 和按钮 2，直接按板子屏幕上的“夹具夹紧 / 夹具松开”。
  夹紧和松开必须交替按；按一次走一段固定行程。

结束运行：
  1. 先松开所有按钮。
  2. 在命令行按 Ctrl + C，等出现“停止”。
  3. 再关 24V 电源、12V 电源。


----------------------------------------------------------------------
 六、命令速查（每次启动就看这里）
----------------------------------------------------------------------

进入项目文件夹：
  cd /d "E:\master manipulator\主从协同逐步调试（未完善）"

检查主手：
  python tools\3dtouch\code\touchpy\check_device.py

校准主手（笔插墨盒）：
  python tools\3dtouch\code\touchpy\calibrate.py

干跑（不动电机）：
  python pc\bridge.py

正式运行：
  python pc\bridge.py --live

看串口号（找不到 COM6 时用）：
  python -m serial.tools.list_ports -v

换串口运行（例如板子是 COM7）：
  python pc\bridge.py --live --port COM7


----------------------------------------------------------------------
 七、出问题怎么判断
----------------------------------------------------------------------

1. 提示“打开主手失败 / 设备可能已被另一个程序占用”
   - 关掉 Touch Diagnostic、厂家演示程序，或别的 python 窗口。
   - 设备同一时间只能被一个程序使用。

2. 提示“打开串口 COM6 失败”
   - 板子的 USB 线没插好，或者串口号不是 COM6。
   - 运行上面“看串口号”的命令，找到 “USB-SERIAL CH340 (COMx)”，
     再用 --port COMx 重新运行。

3. 板子屏幕黑一下、闪一下
   - 正常。板载 CH340 的 DTR/RTS 接在复位上，打开串口会让板子重启。
     脚本已经处理，等 1 秒就好。

4. 按了按钮但机台不动
   - 24V 电源没开、驱动器没使能、急停被按下，或者机台已经到限位。
   - 先松按钮、Ctrl+C，再检查硬件。

5. 机台方向反了
   - 直线反了：运行命令后面加 --no-invert1
   - 旋转反了：运行命令后面加 --invert2
   例：python pc\bridge.py --live --no-invert1

6. 任何异常、异响、撞机
   - 第一反应：拍急停、松按钮、Ctrl+C。
   - 不要先去看屏幕上的报错。


----------------------------------------------------------------------
 八、绝对不要做的事
----------------------------------------------------------------------

- 不要在机台运动时把手伸进运动范围。
- 不要按着笔上的按钮去点屏幕（会抢控制权）。
- 不要把驱动器的 ENA 当急停用，断使能可能让机构掉下来。
- 不要跳过“干跑”，直接 --live。
- 不要修改固件或接线后不重新校准就运行。
- 不要在开着 24V 的情况下插拔电机线。

======================================================================
 一句话流程：
 接线 -> cd 到项目 -> check_device -> calibrate（需要时）
 -> bridge.py 干跑 -> bridge.py --live -> Ctrl+C -> 断电
