# 三电机与隔离板接线

本程序使用 F407 的 GPIOC `PC0` 至 `PC5` 控制三台 SRX02-E 驱动器。不要使用原先
`PA0/PA1` 的单电机接线；`PA0` 是该示例工程的板载按键（KEY1）。

驱动器脉冲输入采用 **共阳极** 接法：三台驱动器的 `STEP+`、`DIR+` 并接到隔离板输出侧
的 `+5V`，隔离板的 `Y` 输出分别接各自的 `STEP-`、`DIR-`。

## 1. F407 到高速光耦隔离板输入侧

隔离板输入电压选择为 `3.3V`。每个输入通道的 `Xn-` 接 F407 任意一个 `GND`；
`Xn+` 接下表 GPIO。若隔离板是公共端输入（共阳输入），则把各 `Xn+` 并接到 `3.3V`，
各 `Xn-` 接相应 GPIO。

| F407 GPIO | 隔离板输入 | 含义 |
|---|---|---|
| PC0 | X1+ | M1 STEP |
| PC1 | X2+ | M1 DIR |
| PC2 | X3+ | M2 STEP |
| PC3 | X4+ | M2 DIR |
| PC4 | X5+ | M3 STEP |
| PC5 | X6+ | M3 DIR |

## 2. 隔离板到 SRX02-E 输出侧（共阳极）

```text
隔离板输出侧 VCC(+5V) ──┬── M1 STEP+、M1 DIR+
                        ├── M2 STEP+、M2 DIR+
                        └── M3 STEP+、M3 DIR+

Y1 -> M1 STEP-
Y2 -> M1 DIR-
Y3 -> M2 STEP-
Y4 -> M2 DIR-
Y5 -> M3 STEP-
Y6 -> M3 DIR-
```

| 隔离板输出端 | 接到 | 说明 |
|---|---|---|
| VCC（输出侧 +5V） | 三台驱动器的 STEP+、DIR+（六根并接） | 共阳极公共端 |
| Y1 / Y3 / Y5 | M1 / M2 / M3 的 STEP- | 步进脉冲 |
| Y2 / Y4 / Y6 | M1 / M2 / M3 的 DIR- | 方向电平 |

要点：

- **输出电平跳帽必须选 `5V`。** 共阳接法靠把 `STEP-`/`DIR-` 拉到与 `+5V` 相同的电平
  来熄灭驱动器内部光耦；若跳帽选 `3.3V`，"关断"时两端仍有约 1.7V 压差，光耦可能微导通，
  表现为误步、丢步或多走。
- 共阳时 `STEP+` 与 `DIR+` **必须**并接在同一 `+5V` 上；但 `STEP-` 与 `DIR-`
  **绝不能短接**，否则脉冲会把方向一起拉低。
- 逻辑极性：隔离板 `Y` 是高电平有效，共阳接法下驱动器内部光耦在 `Y` 为**低**时导通，
  因此 STEP/DIR 的有效电平与共阴极接法相反。每个 STEP 脉冲只产生一次光耦电流上升沿，
  驱动器的计数与行程不受影响；若方向与预期相反，改 `User/main.c` 里对应轴的
  `MOTOR1_DIR_INVERTED` / `MOTOR2_DIR_INVERTED` / `MOTOR3_DIR_INVERTED`。
- 隔离板输出侧使用隔离的稳定 5V：`5V 正极 -> VCC`、`5V 负极 -> GND`、跳帽选 `5V`。
  六路共阳极输入合计约 50~90 mA（每路 8~15 mA），确认这路 5V 电源和导线余量足够。

## 3. 驱动器与电机

每台 SRX02-E：

```text
24V+ -> V+
24V- -> V-
电机两相 -> A+ / A- 与 B+ / B-
SW11 -> OFF（STEP/DIR 模式）
细分 -> 3200 pulse/rev
```

当前程序不使用 `EN+ / EN-`。首次调试请只接 M1/M2，确认屏幕触控、方向和低速旋转正确，
再接 M3。

## 4. 程序参数（与 `User/main.c` 当前值一致）

| 电机 | 操作方式 | 输出频率 | 行程 | 所需时间 |
|---|---|---|---|---|
| M1（PC0/PC1） | 按住转，松开停 | 1600 Hz | 连续 | — |
| M2（PC2/PC3） | 按住转，松开停 | 400 Hz | 连续 | — |
| M3（PC4/PC5） | 点一次走一段 | 4800 Hz | 26000 脉冲 | 约 5.4 s |

- 转速换算（3200 脉冲/圈）：M1 = 1600/3200 = 0.5 圈/s = **30 rpm**；
  M2 = 400/3200 = **7.5 rpm**；M3 = 4800/3200 = 1.5 圈/s = **90 rpm**。
- M3 行程：65 × 45° = **2925°** = **8.125 圈**；
  3200 × 2925 / 360 = **26000 脉冲**（45° 正好 400 脉冲）。
- M1/M2 松开即停；超过 300 ms 收不到新的触摸上报也会强制停机（触摸芯片异常兜底）。
- M3 的"夹紧"和"松开"必须交替：夹紧后只允许松开、松开后只允许夹紧，
  长按同一按钮只触发一次。

可调参数都在 `User/main.c` 文件顶部：

| 宏 | 作用 |
|---|---|
| `MOTOR1_CONTINUOUS_SPEED_HZ` | M1 连续转速（默认 1600） |
| `MOTOR_CONTINUOUS_SPEED_HZ` | M2 连续转速（默认 400） |
| `MOTOR3_SPEED_HZ` | M3 行程速度（默认 4800） |
| `MOTOR3_STEPS` | M3 每段行程的步数（默认 65） |
| `MOTOR3_DEG_PER_STEP` | M3 每步角度（默认 45） |
| `MOTOR3_PULSES_PER_REV` | 驱动器细分（默认 3200，必须与实际拨码一致） |
| `MOTORx_DIR_INVERTED` | 各轴方向取反 |

M3 的脉冲总数由上述宏自动推导，改步数、角度或细分后不需要再手算 26000。

## 5. 调试开关（`User/main.c` 顶部）

| 宏 | 作用 |
|---|---|
| `ACTIVE_MOTOR_COUNT` | 1/2/3，只启用前几台电机（只接 M1/M2 时设为 2） |
| `MOTOR_OUTPUT_ENABLED` | 设为 0 则不输出脉冲，只调屏幕界面 |
| `LCD_DIAGNOSTIC_MODE` | 设为 1 显示红/绿/蓝三色条，检查屏与 FSMC |
| `ISOLATOR_STATIC_TEST` | 设为 1 用 PC0/PC1 静态电平测隔离板通路 |
