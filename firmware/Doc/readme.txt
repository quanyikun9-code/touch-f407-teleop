【 ！】程序简介：

    STM32F407ZGTx + 4.3 寸电容触摸屏，通过屏幕按键控制三台 SRX02-E 步进驱动器。

    硬件：野火 Fire F407ZG 开发板、FSMC 8080 接口 LCD、GT 系列电容触摸屏，
    三路 STEP/DIR 由 PC0~PC5 输出，经高速光耦隔离板（共阳极接法）驱动三台驱动器。

    功能：

    - 直线推进 / 直线回退：按住持续转，松开即停（M1，1600 Hz，约 30 rpm）
    - 顺时针 / 逆时针旋转：按住持续转，松开即停（M2，400 Hz，约 7.5 rpm）
    - 夹具夹紧 / 松开：点一次走一段固定行程，夹紧与松开必须交替
      （M3，65 x 45 度 = 2925 度 = 8.125 圈 = 26000 脉冲，4800 Hz，约 5.4 秒）

    屏幕底部显示 CLAMP/OPEN 操作计数、M1/M2/M3 运行状态和原始触摸坐标。

    接线与参数细节见工程根目录下的 "三电机接线说明.md"。

/*********************************************************************************************/

【 ！】实验操作：

    1. 按 "三电机接线说明.md" 连接隔离板、驱动器与电机（共阳极，输出跳帽选 5V）
    2. USB 线连接开发板 USB 转串口与电脑，串口助手配置 115200 8-N-1
    3. 编译并下载程序到开发板（Keil 工程：Project\Fire_F407ZG.uvprojx）
    4. 串口会打印启动信息、LCD 与触摸芯片 ID
    5. 触摸屏幕按键控制电机；LCD 初始化失败时板载红灯常亮、程序停在死循环

    首次调试建议只接 M1/M2：把 User\main.c 里的 ACTIVE_MOTOR_COUNT 改成 2，
    确认触控与方向正确后再接 M3。

/*********************************************************************************************/

【 ！】调试开关（User\main.c 文件顶部）：

    ACTIVE_MOTOR_COUNT    1/2/3，只启用前几台电机
    MOTOR_OUTPUT_ENABLED  0 = 不输出脉冲，只调试屏幕界面
    LCD_DIAGNOSTIC_MODE   1 = 全屏显示红/绿/蓝三色条，检查屏与 FSMC
    ISOLATOR_STATIC_TEST  1 = 用 PC0/PC1 静态电平检查隔离板通路
